# Система тестирования Академии Водного транспорта

Учебный сайт для создания и прохождения тестов на любую тему.

## Страница для студентов

Откройте:

```text
index.html
```

На этой странице нет регистрации и нет видимой ссылки на админ-панель. Студент выбирает тест, отвечает на вопросы и получает результат с разбором ответов.

## Админ-панель

Админ-панель вынесена на отдельный эндпоинт:

```text
admin.html
```

Временный доступ:

```text
Логин: rut123
Пароль: miit2026
```

В админ-панели можно:

- создать тест на любую тему;
- добавить любое количество вопросов;
- добавить несколько вариантов ответа;
- отметить правильный вариант;
- редактировать и удалять готовые тесты.

## Запуск через локальный сервер

Если браузер ограничивает сохранение данных при открытии файлов напрямую, запустите локальный сервер из папки проекта:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

После этого откройте:

```text
http://127.0.0.1:4173/index.html
http://127.0.0.1:4173/admin.html
```

## Хранение данных

Тесты сохраняются в `localStorage` браузера. Это подходит для учебной демонстрации без сервера и базы данных.
